WebMCP

浏览器内直调

页面在 navigator.modelContext 注册四个工具，agent 无需额外服务即可起卦、读卦、取原典。

navigator.modelContext

服务只做三层

越界的内容留给会话层与上层 AI。API 响应里没有 expiresAt、advice 这类字段。

象数骨架

六爻原始值（6/7/8/9）、本卦、变卦、互卦、动爻位置与数量、朱熹变爻取象规则。

不包含 有效期、能否重占等状态判断。

原典文本

卦辞、爻辞、彖传、象传（大象 + 小象）原文，按底本寻址，当前为通行本。

不包含 白话译文、个人处境的安慰话。

客观象意

八卦自然属性与核心意象、爻位关系（当位、得中、应与、承乘）。

不包含 行业 / 感情 / 财务的定制化推演与吉凶断言。

HTTP API

Base URL /api/v1，全部响应带 CORS。成功为 { ok: true, data }，失败为 { ok: false, error: { code, message } }。

方法路径说明
GET/api/v1服务自述：三层、排除边界、底本、八卦字典
GET/api/v1/health健康检查
GET/api/v1/hexagrams六十四卦索引
GET/api/v1/hexagrams/:id单卦：原典 + 象意
POST/api/v1/readings六个 6–9 的爻值 → 三层读卦
POST/api/v1/cast随机起卦 → 六爻值 + 三层读卦
随机起卦 
curl -X POST https://651372.xyz/api/v1/cast \
  -H 'content-type: application/json' \
  -d '{}'
按六爻值读卦（6=老阴 7=少阳 8=少阴 9=老阳，自下而上） 
curl -X POST https://651372.xyz/api/v1/readings \
  -H 'content-type: application/json' \
  -d '{"numbers":[6,7,8,9,7,8],"edition":"通行本"}'
响应结构 
{
  "ok": true,
  "data": {
    "schema": "zhouyi.reading/v1",

    "text":     { "edition": {}, "primary": {}, "transformed": {}, "nuclear": {} },
    "imagery":  { "primary": {}, "transformed": {}, "nuclear": {} }
  }
}

WebMCP

webmcp.js 在支持 WebMCP 的浏览器里把起卦能力挂到 navigator.modelContext，agent 不必知道 API 路径，直接选工具即可。

检测 WebMCP 支持…

工具作用
zhouyi_cast随机起卦
zhouyi_read按六个 6–9 的爻值读卦
zhouyi_hexagram按 1–64 卦号取原典与象意
zhouyi_list_hexagrams六十四卦索引
页面注册后的调用形态 
// 页面加载时自动注册（webmcp.js）
import './webmcp.js';

// agent 侧按名字选工具，参数与 API 一致
zhouyi_cast({ edition: '通行本' });
zhouyi_read({ numbers: [6, 7, 8, 9, 7, 8] });
zhouyi_hexagram({ id: 1 });
zhouyi_list_hexagrams({});

工具走同一个 /api/v1，返回内容同样只有三层——不含有效期，也不含个人化断语。 未支持 WebMCP 的浏览器会安静跳过注册，页面其余功能不受影响。
